5tratMux v0.9.42-dev is the signed DEV candidate for the v0.9.42 hashrate and
service-power release. It contains the same source changes as v0.9.42 and is
published separately so DEV-channel 5tratumOS nodes can validate the exact
candidate feed.

Hardware telemetry is authoritative, Avalon lifetime averages are excluded,
the accepted-proof fallback uses bounded one-minute and five-minute windows,
and a true zero cannot revive an old fleet total. The release also adds the
confirmed, OS-owned MUX power-off and power-on lifecycle while preserving saved
miner pools, wallets, licence state and application data.

The complete 460-test MUX suite and 104-test OS suite passed. AMD64 and ARM64
packages passed protected-runtime and health verification, and the corrected
AMD64 DEV build was validated live on the `.235` node.
