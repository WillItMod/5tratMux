5tratMux v0.9.21 is a corrective interface and monitoring release following
the v0.9.20 control-surface rebuild.

The release fixes browser, kiosk, StratumOS sidebar, tablet and phone layouts.
Live, Route, Automate, Setup and System now remain within the available
viewport without horizontal page overflow. Phone navigation, full-screen
sheets, route controls, result cards and dialogs have been corrected, and the
simplified mobile interface remains an explicit user choice.

Full-screen monitoring again keeps the routing animation, MUX reason, trigger
graph and leading 5tratPack/model evidence together. Completed MUX responses
remain available as the latest recorded decision after routes are restored, so
the reason and graph do not disappear when an attack window closes. Monitor
text size controls and motion controls remain available.

The retained workspace animation transform that could displace fixed dialogs
after scrolling has been removed. The mobile More menu, MUX evidence sheet,
Manual MUX dialog and Technology Explorer now remain anchored to the visible
screen. The Live block-result card also collapses cleanly into a two-column
phone layout.

Routing, warm connections, 5tratPacks, AI settings, licensing state, miners,
pool details and MUX-to-app live hash injection are unchanged. Existing state
is preserved during the signed update.
