# 5tratMux 0.9.54 — Local AI network and model recovery

Local AI market research now tries every safe address returned by DNS within a bounded deadline. A failed IPv6 route or CDN endpoint can no longer discard an otherwise reachable CoinGecko response and incorrectly force BTC, BCH, DGB, DOGE and LTC into Hold-Route together. When upstream research genuinely fails, the interface reports a safe diagnostic category without exposing network details.

The Local AI panel can now update an older managed runtime in place and clearly offers to download and start a newly selected model. Runtime updates preserve downloaded models, model selection, resource preferences and the previous On/Off intent. A stopped runtime's stale memory-pressure message no longer blocks an explicit model recovery, while current installation errors still stop the operation safely.

This release is paired with 5tratumOS 0.8.10 and managed Local AI runtime 0.1.3 for the signed in-place upgrade path. Existing licences, routing settings, installed models and application data are preserved.

Native compiled packages are provided for Linux AMD64 and ARM64 through the signed app updater.
