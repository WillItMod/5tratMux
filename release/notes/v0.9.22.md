5tratMux v0.9.22 is an emergency forward-version rollback to the proven
v0.9.18 application and interface.

This release removes the v0.9.20/v0.9.21 control-surface and 5tratPacks
overhaul. It restores the original seven-tab layout, established responsive
behaviour, live MUX attack evidence and graph, fleet-health recovery, Luna
pricing support, block provenance, local endpoint handling, and trial safety
fixes shipped through v0.9.18.

The higher version number is intentional. It allows systems already running
v0.9.20 or v0.9.21 to install the known-good code through the signed updater
without a downgrade exception.

Local settings, licence state, miner identities, wallets, and routing state are
preserved by the updater.
