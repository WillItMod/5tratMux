# 5tratMux 0.9.57 DEV

DEV counterpart of [5tratMux 0.9.57](https://github.com/WillItMod/5tratMux/releases/tag/v0.9.57), including source-bound exact
Local AI percentages, clear conflicting-allocation holds, miner compatibility,
concurrent worker-state persistence, late win attribution and durable
notification acknowledgment retry backoff.

The signed manifest uses the updater's required `MAIN` runtime-channel marker.
The `-dev` version and GitHub prerelease identify the DEV distribution. Existing
licence, mission settings, worker allocations and application state are retained.

Validation includes 1,022 Python tests, the JavaScript suites, real Qwen 0.8B,
2B and 4B guidance checks, and successful signed DEV then MAIN installations
on the test node. These advisory checks do not claim a live hashrate endurance
test; the node's existing worker allocations and settings were preserved.
