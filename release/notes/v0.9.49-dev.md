5tratMux 0.9.49-dev is the DEV counterpart of 0.9.49. It contains the same protected application and browser payloads, with DEV version metadata.

It restores automatic MUX Attack monitoring and app-validated local launches for the Local 5TRATMUX provider, while retaining paid entitlement, evidence, threshold, persistence, scope, route health, cooldown and restoration checks. Ordinary model fleet comparisons do not acquire launch authority.

Managed model installation requires the compatible 5tratumOS 0.8.4 catalogue and runtime. See the 0.9.49 release notes for installation requirements and experimental-model limits.
