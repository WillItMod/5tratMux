5tratMux v0.9.41 is the MAIN release of UI overhaul 3.

Hashrate reporting now uses a recent blended estimate instead of allowing the
session lifetime average to dominate the display. Hardware standby telemetry
takes precedence, so an idle miner is shown as standby and excluded from live
fleet hashrate.

The Block Win chalkboard now uses coin artwork, larger coin labels, complete hit
timestamps and relative ages. Win attribution distinguishes MUX Attack, AI
control, manual routing and older records without provenance. A server-backed
claim and acknowledgement path prevents the same MUX/OS celebration from being
replayed across browsers, reloads and restarts; pool-app celebrations remain
independent.

Fleet and route views reject stale cross-route samples while preserving miners
that are intentionally active on multiple physical sessions. This release also
includes the UI overhaul's responsive layout, localization, automation,
opportunity-monitoring and operational-health improvements.

The complete 454-test suite passed. Native AMD64 and ARM64 packages were
verified, and the signed AMD64 package was tested with 5tratumOS v0.7.7 on the
.235 DEV node. The Avalon Q remained correctly classified as standby, the
chalkboard outcome totals and coin presentation were verified in the browser,
and the updater preserved licence and trial state.

Local settings, licence state, miner identities, wallets, application data and
routing configuration are preserved by the updater.
