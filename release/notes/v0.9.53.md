# 5tratMux 0.9.53 — Block metrics and attribution

Block history now displays recorded pool hashrates correctly and distinguishes payout-matched blockchain detections from blocks with miner attribution. Detection sources such as “live” are no longer presented as AI model names.

Accepted submission evidence now survives application restarts. When an exact chain and block-hash match becomes available, Mux can fill missing miner, control, allocation and hashrate information without adding a duplicate win. Current miner settings are no longer treated as proof of who controlled an older solve. Pool-supplied Miningcore worker names are preferred over payout addresses.

Historic details remain unavailable when no matching evidence exists. This update does not manufacture attribution or change routing policy. Existing licences, local AI configuration, allocations and pool data are preserved.

Native compiled packages are provided for Linux AMD64 and ARM64 through the signed app updater. A separate OS or pool-app update is not required.
