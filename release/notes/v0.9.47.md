5tratMux 0.9.47 adds Fluminer onboarding and improves mixed SHA256/Scrypt fleet routing, visibility and Scrypt job handling.

- Discover Fluminer L2 miners through their web API. Try the factory `root` / `root` login first and request credentials if needed. Read telemetry and configure pools while retaining fallbacks and checking saved settings.
- Keep newly added miners available in AI scope without a full app refresh, preserve pending selections, and show selected miners in Overview while their first routing plan is forming.
- Keep miners eligible for AI routing when management telemetry is unavailable but live Stratum and accepted work prove activity. Hashrate uses fresh hardware readings, then current accepted-work estimates, with known capacity labelled separately while an estimate forms.
- Give SHA256 and Scrypt independent AI portfolios. Each algorithm allocates 100% among compatible destinations; Scrypt routing compares PowPow and AxeDGB Scrypt. MUX responses and the SHA256 reserve respect algorithm compatibility.
- Align Overview delivery counts, AI live health, route percentages, probability estimates and usage forecasts with current compatible work. Offline, standby and warm-only connections do not count as accepting miners.
- Preserve Scrypt difficulty and job ordering, and prevent unnecessary cached-job replay during active pool difficulty changes. Repeated identical Scrypt work no longer restarts nonce search when the effective miner difficulty and connection context are unchanged. Cache routing controls between settings changes to reduce work in the Stratum forwarding path.
- Use the serving LAN address in Setup on hosts with multiple interfaces. Keep route badges numeric and compact on desktop and narrow screens. Diagram percentages show the share of currently delivering miners at each destination; mixed SHA256/Scrypt summaries retain separate hashrates.

Fluminer L1 shares this API adapter but has not been validated on a physical L1. Miners continue to use the shared Stratum listener on port 7331.

This cumulative update retains the external-pool removal and Scrypt compatibility fixes included in earlier releases.
