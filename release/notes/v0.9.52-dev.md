# 5tratMux 0.9.52 DEV — Licence backup and PC replacement

This DEV candidate includes the same licence-proof backup and five-move
self-service restoration feature as MAIN 0.9.52, together with all 0.9.51
Local AI and MUX reliability fixes.

Upload the saved proof in **System → Licensing** after reinstalling or moving
to another PC. The original plan and expiry stay unchanged. The old binding
is retired atomically when the replacement is activated; online old devices
lose access at their next successful licensing check, while offline devices
can retain their existing signed lease/grace until it expires.

The native executable and browser payload are byte-identical to MAIN 0.9.52.
Only version metadata distinguishes this DEV prerelease. Both signed manifests
use the updater's required `MAIN` runtime-channel marker; GitHub prerelease
selection and the `-dev` version identify the DEV distribution.
