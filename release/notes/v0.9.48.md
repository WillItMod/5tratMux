5tratMux 0.9.48 supplies the native routing integration required by the updated MuxFlight in 5tratumOS 0.8.3.

- Support temporary MuxFlight control, fleet recruitment and validated allocation profiles while retaining normal AI and manual routing ownership. Keep lease renewal responsive during AI reviews and preserve control across accounting snapshots.
- Add Local 5TRATMUX to the AI provider selector, with model setup, progress, verification and runtime status for compatible managed installations. Local AI requires a confirmed paid licence; trial access does not include runtime installation, model downloads or inference.
- Validate local-model mission preferences, including BCH priorities and PowPow’s coupled LTC/DOGE rewards. Support plans with four, five or six allocations and retain healthy, mission-compliant allocations when a proposed change does not clear the rebalance margin.
- Improve coin-source freshness reporting and local inference telemetry for the OS widgets. Distinguish reviews that wait for evidence from actual model generation.

Fresh managed Local AI downloads are not enabled by this release: the public runtime catalogue still requires trusted OS distribution metadata. Existing compatible private managed runtimes can continue to operate. A visible provider option does not mean a model has been installed. Qwen 2B/4B and ARM local inference have not been qualified for public use.

This cumulative release retains the previous Fluminer, external-pool and SHA256/Scrypt routing fixes. Runtime images are compiled and browser assets are minified; private application source is not included in this repository or the release images.
