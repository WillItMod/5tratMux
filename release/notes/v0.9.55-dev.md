# 5tratMux 0.9.55 DEV — Miner discovery and connection guidance

DEV counterpart of [5tratMux 0.9.55](v0.9.55.md), including:

- Read-only discovery for identified CGMiner-compatible miners without a
  supported automatic configuration method.
- Discovery that retains a valid miner identity when pool-settings reads are
  restricted or unavailable, while configuration still checks saved settings.
- Earlier local authorization responses with upstream rejection, timeout and
  buffering safeguards before mining work can be forwarded.
- A guided Setup → Miners → optional AI Automation flow, accurate offline route
  labels, and clear manual connection instructions.
- All Local AI network and model recovery corrections from 0.9.54.

The signed manifest uses the updater's required `MAIN` runtime-channel marker.
The `-dev` version and GitHub prerelease identify the DEV distribution. Existing
licence, routing and application state are retained. No companion OS or pool
update is required for this application change.

An accessible management API is still needed for discovery; a successful scan
is not proof of active mining. Validate the live route and increasing accepted
shares. The original reporting user's hardware has not been directly tested.
